# 설계: 지갑 · 화폐 사용처 · 소모품 · 레이드 기믹 · 신규 직업 · 네임드 소굴

> 설계 의도와 수치입니다. 실제 목록(소모품 58종, 레이드 기믹, 직업 무기)은 `runDatagen`이 코드에서 생성하는
> [docs/CONSUMABLES.md](CONSUMABLES.md), [docs/MONSTERS.md](MONSTERS.md), [docs/CLASSES.md](CLASSES.md)를 보세요.

## 1. 죽어도 아이템 유지

- 서버가 시작될 때 `keepInventory`를 켭니다. 죽어도 인벤토리·장비·경험치 레벨은 그대로입니다.
- 직업 경험치 사망 패널티(현재 레벨 진행도 10%)는 그대로입니다. 레이드·던전에서는 아무것도 잃지 않습니다.

## 2. 지갑

- 동전은 인벤토리 칸을 쓰지 않습니다. 동화·은화·금화를 주우면 0.5초 안에 **지갑**(플레이어 데이터, 죽어도 유지)으로 들어갑니다.
- 잔액은 왼쪽 위 직업 패널과 상점 화면에 `3G 2S 1C`처럼 보입니다.
- 상점에서 동전이 필요한 거래를 고르면 지갑에서 그 동전이 결제 칸으로 나옵니다(남은 동전은 창을 닫으면 다시 지갑으로).
  물건을 팔고 받은 동전도 바로 지갑으로 들어갑니다.
- 모험가 메뉴(;)의 송금 탭이나 `/wallet pay <플레이어> <금액>`(예: `3g`, `25s`, `120`)으로 다른 플레이어에게 송금합니다. `/wallet`은 잔액.

## 3. 화폐 사용처 (성장 중에도 조금씩, 고레벨일수록 계속)

| 사용처 | 비용 | 비고 |

| 레이드 입장료 | 보스 구간 상점가 (베르데사 2S → 에테릭스 7G 3S 6C → 스쿠나 11G 4S 3C, 영웅 ×1.5·악몽 ×2) | 입장할 때 파티원마다 지갑에서 |

| 특성 초기화 | 동전 | |
| 재구매 | 판 값 × 1.5 | 상점에 잘못 판 물건(최근 10건) |
| 연금술사 | 소모품 1~3단계, 최상급 일부 | 새 상점(시장) |
| 귀환 주문서 | 은화 3 | 5초 뒤 수도 광장으로 |
| 직업 초기화 주문서 | 금화 4 | 기존 |
| 장신구 강화 | 장신구 강화 구슬 + 장비 강화와 같은 곡선의 동전 | 0.5.24 |
| 장신구 계승 | 계승권 + 구간 무기값의 절반 | 0.5.24 |
| 건축 자재상 | 블록 64개 묶음, 고정가(시세 변동 없음) | 0.5.28 |
| 토지 소유권 증서 | 공적(처음 2장 500, 그 뒤 +250씩; 계정 단위) | 0.5.46 |
| 저주 유물 교환소 | 스쿠나의 손가락(장신구 한 부위 15개, 3티어 장신구 계승권 10개) | 0.5.45 |

- 수입: 일반 몹 동화, 체력 높은 몹 은화·금화, **네임드는 레벨에 비례한 동전**(Lv 20 약 4C → Lv 90 약 1G),
  상점 판매(광석·채집물은 캐기 어려울수록 비싼 고정가, 생활 기술 제작품은 재료 값 × 숙련 배율), 경매 분배금, 길드 의뢰.
  사냥·채광만 해도 쌓이도록 해서 스트레스가 되지 않게 합니다. 어느 상점도 다른 상점의 판매가 이상으로 사 주지 않으므로 사서 되파는 차익은 없습니다. 전리품 상인 토빈(0.5.29)은 직업 장비와 장신구를 길드 가격의 30%로 한꺼번에 사 줍니다.

## 4. 소모품 58종

- 0.5.47부터 스킬은 회복·보호막을 주지 않으므로, 회복은 소모품과 장비 스탯(흡혈·체력 재생 등)으로만 합니다. 마지막 18종은 농작물·생선으로 만드는 요리 전용입니다(1–5등급 12/18/15/10/3종).

- 5단계: 1단계(상점 동화·제작) → 2단계(상점 은화·제작) → 3단계(연금술사 금화, 네임드 드롭) → 4단계(네임드 희귀 드롭·레이드 보상, 일부 연금술사 고가) → 5단계(레이드 보상 전용).
- **지속 효과는 모두 10분**. 같은 효과는 더 강한 쪽이 적용되고, 다른 효과끼리는 겹칩니다(도핑).
- 즉시 회복류는 같은 쿨타임 그룹을 씁니다(체력 회복끼리, 마나 회복끼리) — 보스전에서 연타로 버티지 못하게.
- 새 효과 10종(직업 스탯과 같은 체계): 격노(기본 공격·사격 피해), 철갑(받는 피해 감소), 정밀(치명타 확률), 비전(스킬 피해),
  집중(재사용 대기시간), 명경(MP 회복), 재생력(4초마다 체력 회복), 행운(장비·동전 드롭), 지혜(직업 경험치), 사냥꾼(보스 피해).
- 예: 선두(드래곤볼) — 체력 80% 즉시 회복 + MP 50% + 배고픔 회복. 피닉스의 깃털 — 죽을 피해를 받으면 체력 50%로 부활(소모).

## 5. 레이드 기믹 (즉사급)

- 보스마다 즉사 기믹 1~3개(쉬운 보스 1개, 어려운 보스 3개). 체력 % 도달 시 처음 발동하고 이후 일정 주기로 반복합니다.
- **기믹과 기믹 사이는 최소 45초**, 전투 시작 후 30초 동안은 기믹이 없습니다. 기믹 중에는 일반 패턴이 쉽니다.
- 즉사 피해는 방어·저항을 무시하지만, 불사의 토템·피닉스의 깃털은 막을 수 있습니다(기사왕의 아발론 부활은 0.5.47에 선정의 검으로 바뀌어 없습니다).
- 개인 기믹(자기만 잘하면 됨)과 협동 기믹(유격훈련처럼 다같이)이 섞여 있습니다. 협동 기믹은 인원에 맞춰 요구량이 정해져서
  **솔로는 쉽게 넘길 수 있습니다(의도)**.

| 보스 | 기믹 |
|---|---|
| 베르데사 | 씨앗나무(협동: 파티 인원 + 1그루를 18초 안에 모두 베기) |
| 아라크네 | 독의 홍수(개인: 거미줄 고치 안으로) |

| 네프레케트 | 유사(개인: 넷 중 무너지지 않는 받침대 위로) |

| 이그니스 | 태양 섬광(개인: 등 돌리기), 불사조의 알(협동: 제한 시간 안에 수호 정령 처치) |

| 에테릭스 | 사건의 지평선(개인: 바깥으로 도망), 별의 봉인(협동: 봉인마다 한 명씩), 공허의 심판(협동: 표식 대상에게 모이기) |
| 스쿠나 | 십종영법술 마허라(75%, 한 번: 마허라가 서 있는 동안 스쿠나 무적, 피해에 적응하며 여덟 번 돌면 전멸), 영역전개 복마어주자(50%부터 150초마다: 영역 밖으로 나가거나 간이영역 원 안에서 필중 참격을 피함) |

## 6. 신규 직업 2종

- **사신**(블리치): 사신 → 부대장 → 대장 → 총대장. 참백도(태도·대검·쌍검·쇄겸·창·클로·사복검), 귀도(파도·박도), 순보, 시해·만해.
  - 패시브: 순보(이동 +8%·회피 5%) → 시해(스킬 피해 +8%) → 만해(기본 공격 +10%·공격 속도 +5%) → 무월(재사용 -8%·보스 피해 +15%). 레벨 보상: 스킬 재사용 대기시간(레벨당 0.1%). 고유 기술: 순보(11블록 순간 이동).
  - 교관 우라하라 키스케(궁수 공원의 우라하라 상점), 대표 무기 홍희. 시련: 혼장 → 참백도의 이름 → 만해 수행 → 우에코 문도.
- **헌터**(헌터×헌터): 헌터 → 넨 능력자 → 프로 헌터 → 트리플 헌터. 낚싯대·요요·가위바위권·트럼프·사슬·손가락 총·우산·넨사·크레이지 슬롯·백식관음·투척침 등.
  - 패시브: 텐(받는 피해 -5%·체력 +2) → 교(치명타 +10%) → 코(15% 두 번 적중) → 제약과 서약(스킬 피해 +10%·초당 MP +2). 레벨 보상: 치명타 피해(레벨당 0.3%). 고유 기술: 엔(32블록 안의 적을 드러냄).
  - 교관 비스켓 크루거(전사 구역의 헌터 협회 출장소), 대표 무기 가위바위권. 시련: 헌터 시험 → 수견식 → 키메라 앤트 토벌 → 암흑대륙.
- 기존 직업과 같은 구조: 무기 26종(1차 3·2차 7·3차 7·4차 9, 0.5.24), 무기마다 스킬 3~4개, 방어구 10세트, 무기 각인 10종 + 방어구 각인 18–19종(부위마다 10종 이상), 전직 시련 4개, 교관.

## 7. 네임드 소굴 22곳

- 바이옴을 새로 만드는 대신(오버월드 바이옴 추가에는 TerraBlender가 필요) **구조물 + 그 구역의 스폰 목록**으로 "네임드가 자주 나오는 곳"을 만듭니다. 구조물 상자(소굴 둘레 40블록 포함) 안에서는 일반 몬스터 + 그 네임드(평소의 2배 비율, 6–20%)만 나오고, 네임드 간 거리 제한도 20블록으로 줄어듭니다.
- 22곳 모두 한 구조물 세트(약 448블록 간격의 칸마다 많아야 하나)를 써서 서로 겹치지 않고, 칸마다 그 바이옴에 맞는 소굴 하나가 골라집니다. 마을 근처(6청크), 수도 근처(320블록), 엔드 중앙 섬에는 생기지 않습니다.
- 모양: 피라미드(전갈왕·미친 돼지·성운 기사), 지구라트(산적·정글 추적자·마그마 거수), 요새(고블린·서리 늑대·총잡이·위더 기사), 돔(황금 엔더맨·버섯 주술사·공허의 감시자), 첨탑(마녀·익사한 해적·영혼 수확자·코러스 망령), 거목(고대 트렌트, 윈디고는 마른 고목), 지하 미궁 + 지상 등대 탑(동굴 트롤·자수정 파수꾼·메아리 추적자). 미로는 53–77블록, 랜드마크 높이 30–75블록.
- 미로는 소굴마다 다르고(시드), 보물 상자 위치도 매번 다릅니다: 입구 옆 20% · 가장 깊은 곳 35% · 먼 막다른 길 45%. 상자 옆에서 그 네임드가 지키고, 다른 막다른 길에 보급 통이 최대 3개.
- 보상: 동전 항상 + 보상 1개 항상(+60%로 1개, 그중 25%로 1개 더). 보상은 소모품 55% / 장비 45%(그 네임드 레벨 범위). 진화의 에테르와 정수 포함.
