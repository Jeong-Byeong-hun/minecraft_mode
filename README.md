# Minecraft Mode

Minecraft **26.3** (Java Edition) Fabric 모드. 새 광물·도구·갑옷, 출혈 효과, 적대적 몹과 미니보스, 인챈트, 코인 경제, 4차 전직 직업 시스템을 추가한다.

## 콘텐츠

| 분류 | 내용 |
|---|---|
| 미스릴 | 광석(Y -64~16, 철 곡괭이 이상, 청크당 약 33개 — 다이아 24·철 94 사이) → 원석 → 주괴/조각/블록. 도구 5종 + 갑옷 4종 (철과 다이아 사이, 흑요석 채굴 가능, 갑옷 세트 방어 19·강도 4) |
| 알루미늄 | 광석(Y -16~112, 돌 곡괭이 이상, 청크당 약 56개) → 원석 → 주괴/조각/블록 |
| 플라스틱 | 석탄×2 + 슬라임볼 → 판 4장 / 말린 켈프 블록 제련 → 판 1장 / 판 9장 → 블록 |
| 출혈 효과 | 40틱마다 1 피해(레벨당 주기 절반), 이동속도 -10%, 독과 달리 죽을 수 있음 |
| 광산 약탈자 | Y 40 미만 동굴에 스폰(동굴 몬스터의 약 6%). 곡괭이 근접공격, 40% 확률로 출혈 5초. 미스릴 원석·동화·은화 드롭 |
| 미스릴 골렘 (미니보스) | Y 0 미만에서 드물게, 반경 64블록에 1마리만. 체력 150·방어 10, 보스바 표시, 출혈 면역. 8초마다 지면 강타(반경 4.5, 피해 8 + 넉백 + 출혈). 미스릴 원석 블록·주괴·은화·금화 드롭 |
| 인챈트 (75종) | 검·도끼·활·쇠뇌·채굴 도구 각 10종, 방어구 버프 10종(착용자 전용) + 오라 10종(반경 10블록, 같은 오라는 최고 레벨만 적용, 버프와는 중첩), 기존 5종. 대부분 I~V. 전체 목록: [docs/ENCHANTMENTS.md](docs/ENCHANTMENTS.md) |
| 경제 | 동화 9 = 은화 1, 은화 9 = 금화 1. 플레이어가 죽인 적대 몹이 코인 드롭(보스는 금화). 상점 4종(잡화점·대장간·식료품점·보석상)에서 사고팔기 |
| 시세 변동 | 거래할 때마다 그 상품의 시장 압력 +1(최대 20), 1분마다 -1. 압력 1당 가격 +10% — 많이 팔면 같은 코인에 물건이 더 필요하고, 많이 사면 코인이 더 든다. 월드 전체 공유·저장 |
| 직업 (5종 × 4차) | 전사(→검투사→버서커→기사왕), 도적(→닌자→어쌔신→그림자 군주), 법사(→캐스터→대마도사→그랜드 캐스터), 궁수(→레인저→아처→영웅왕), 해적(→선장→사황→해적왕). 차수마다 패시브 1개. 레벨 10/25/45/70에 전직(K 키 직업 창), 2차부터 정수·골렘의 핵·네더의 별 필요 |
| 직업 무기 (115종) | 직업마다 23종(1차 3·2차 6·3차 6·4차 8), 무기마다 고유 스킬 3개(4차 4개, 궁극기 포함) — 총 385개. R/G/V/Z 키로 시전, MP와 재사용 대기시간. 누구나 들 수 있지만 직업·차수·레벨이 맞아야 스킬·각인이 작동(아니면 기본 공격만). 높은 차수·레벨일수록 기본 위력이 높음. 직업 길드에서 동전+정수로 구매 |
| 정수 각인 | 몬스터와 철 이상 광석에서 나오는 정수로 정수 각인대에서 직업 무기에 최대 3줄 각인. 직업별 각인 10~11종, 같은 각인은 중첩(예: 평타 반경 1.5×3 = 4.5블록) |
| 스킬 이펙트 | 새로 그린 파티클 12종(색 지정), 투사체(표창·쿠나이·총알·포탄·마력탄·검기 등), 직업 HUD(레벨·EXP·MP·스킬 쿨다운) |

직업·무기·스킬·각인 전체 목록과 수치: [docs/CLASSES.md](docs/CLASSES.md)

조합법
- 잡화점: `알루미늄 주괴 ×3 / 플라스틱 판·에메랄드·플라스틱 판 / 플라스틱 판·상자·플라스틱 판`
- 대장간 = 잡화점 + 대장장이 작업대, 식료품점 = 잡화점 + 건초 더미, 보석상 = 잡화점 + 다이아몬드, 직업 길드 = 잡화점 + 정수
- 정수 각인대: `정수 ×3 / 다이아몬드·미스릴 주괴·다이아몬드 / 흑요석 ×3`, 응축된 정수 = 정수 ×9

관리자 명령어(권한 2): `/job info|set|level|exp|mana|cooldowns|cast`

## 개발 환경

- JDK 25 (Temurin), Gradle 9.7.1(wrapper), Fabric Loom 1.18, Fabric Loader 0.19.5, Fabric API 0.162.0+26.3
- 26.x는 난독화가 없어서 매핑 없이 Mojang 공식 이름을 그대로 쓴다.

```bash
./gradlew build              # build/libs/minecraft_mode-<ver>.jar
./gradlew runClient          # 개발용 클라이언트 실행
./gradlew runDatagen         # 레시피/모델/태그/번역/월드젠/인챈트 JSON, 직업 무기 텍스처 → src/main/generated, docs/CLASSES.md
./gradlew runClientGameTest  # 자동 테스트 (월드 생성 → 검증 → 스크린샷 build/run/clientGameTest/screenshots)
java tools/TextureGen.java src/main/resources/assets/minecraft_mode/textures  # 텍스처 재생성
```

설치: `build/libs/minecraft_mode-<ver>.jar`를 Fabric Loader + Fabric API가 설치된 26.3 클라이언트/서버의 `mods/` 폴더에 넣는다.

## 텍스처

모든 텍스처는 직접 그린다(바닐라 에셋을 읽지 않음). 일반 텍스처는 `tools/TextureGen.java`(+ `tools/ClassArt.java`: 파티클·정수·각인대 등), 직업 무기 115종은 데이터 생성 단계에서 무기 정의의 유형·차수·색으로 그린다(`client/datagen/art`).

- 아이템(주괴·조각·원석·갑옷·플라스틱 판): 16x16 문자 격자 + 5단계 팔레트
- 도구: 대각선 축 위의 모양 함수(자루 왼쪽 아래, 머리 오른쪽 위)
- 돌/심층암 바탕·광석 결정·금속 블록·원석 블록: 시드 고정 절차 생성(이어 붙여도 이음새 없음)
- 갑옷 착용 텍스처: 휴머노이드 모델 박스 UV에 맞춰 면 단위로 칠함(성인 64x32, 아기 64x64)

색이나 모양을 바꾸려면 파일 위쪽의 `Palette`와 격자를 고치고 다시 실행한다.
