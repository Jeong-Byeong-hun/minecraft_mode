# 인챈트 목록

Minecraft Mode가 추가하는 인챈트 75개. 모두 인챈트 테이블·주민 거래·보물 상자에서 나온다(일부 최고 레벨은 모루 합성 필요).

- **버프**: 착용자 본인에게만 적용. 부위마다 정해져 있어 같은 버프가 두 번 계산되지 않는다.
- **오라**: 반경 10블록 안의 모든 플레이어(본인 포함)에게 적용. 같은 오라는 여러 개가 겹쳐도 **가장 높은 레벨 하나만** 적용된다. 오라와 같은 종류의 버프는 함께 적용된다(예: 힘 II + 힘의 오라 V = 공격력 +7).
- 이 문서는 생성된 데이터(src/main/generated)에서 만든다. 수치를 바꾸면 datagen 후 다시 생성할 것.
